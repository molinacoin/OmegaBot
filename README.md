# OmegaBot 🤖

Bot automatizado desenvolvido para acompanhar o projeto MolinaCoin.

## 🚀 Objetivo

O OmegaBot foi criado para fornecer informações, comandos e sinais relacionados ao projeto de forma rápida através do Telegram.

## 📱 Telegram

O bot possui comandos para consulta de status e informações do projeto.

## 🛠️ Tecnologias

- Python
- Telegram Bot API
- GitHub
- Render

## 📂 Estrutura

Este repositório contém os arquivos necessários para execução e documentação do OmegaBot.

## ⚙️ Hospedagem

O projeto pode ser executado em serviços de hospedagem como o Render.
